## 🌐 About the Project

CAPACITY CONNECT is a digital capacity-building and learning management portal designed to support structured learning, training and competency development.

The platform aims to bring learning resources, courses, learning paths and assessments together in one digital environment.

It is designed to make learning more accessible, organized and trackable for learners and training administrators.

## 🎯 Problem Statement

Traditional training and capacity-building activities can face challenges such as:

- Difficulty accessing learning resources in one place.
- Limited visibility into individual learning progress.
- Challenges in organizing structured learning paths.
- Difficulty assessing competencies and learning outcomes.
- Need for better coordination between learners and trainers.

## 💡 Proposed Solution

CAPACITY CONNECT proposes an integrated digital learning platform with dedicated learning and training experiences.

## ⭐ Key Features

The learner-side prototype demonstrates:

- **Dashboard:** Overview of the learner's learning activities.
- **Courses:** Access to available courses and learning modules.
- **Learning Paths:** Structured learning journeys.
- **Learning Resources:** Access to educational materials.
- **My Learning:** View and manage learning activities.
- **Competencies:** Explore competency development.
- **ConnectAI:** AI-assisted learning support interface.

Additional proposed platform capabilities include:

- MCQ-based assessments.
- Learning progress tracking.
- Certificates and notifications.
- Trainer and administrator dashboards.
- Learning analytics and competency mapping.

## 👥 Intended User Roles

1. **Learner/Trainee:** Access courses, resources and learning paths.
2. **Trainer:** Organize and support training activities.
3. **Administrator:** Manage learning resources and platform activities.

*Note: The learner-side prototype is demonstrated in the project. Additional trainer and administrator workflows are part of the proposed platform scope.*

## 🔄 Project Workflow

Learner Dashboard → Browse Courses → Select Learning Path → Access Resources → Complete Learning Activities → Track Progress
